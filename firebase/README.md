# Firebase config files

These files are not committed. Download them from the Firebase console and place them here:

| Path                            | Firebase project | App ID                           |
| ------------------------------- | ---------------- | -------------------------------- |
| `dev/GoogleService-Info.plist`  | returnsafe-dev   | iOS `com.returnsafe.app.dev`     |
| `dev/google-services.json`      | returnsafe-dev   | Android `com.returnsafe.app.dev` |
| `prod/GoogleService-Info.plist` | returnsafe-prod  | iOS `com.returnsafe.app`         |
| `prod/google-services.json`     | returnsafe-prod  | Android `com.returnsafe.app`     |

For EAS cloud builds, upload them as EAS file environment variables instead of committing them.
